# AGCC — Ground Contact Calculator

Prototype monorepo. Not a production application.

---

## Backend

All commands run from `agcc/backend/`.

**Install:**
```sh
pip install -e ".[dev]"
```

**Run tests:**
```sh
pytest
```

**Lint:**
```sh
ruff check .
```

**Type-check:**
```sh
mypy src/agcc
```

---

## Frontend

All commands run from `agcc/frontend/`.

**Install:**
```sh
npm install
```

**Run tests:**
```sh
npm test -- --run
```

**Build:**
```sh
npm run build
```
